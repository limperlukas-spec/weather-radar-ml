# 0.6 real RADKLIM reference benchmark

## Status

Completed.

Version 0.6 establishes the first learned precipitation-forecast reference on
real RADKLIM-YW data. The purpose of this milestone is not to claim
state-of-the-art nowcasting performance. It verifies that the learned forecast
pipeline produces reproducible, held-out skill over a transparent persistence
baseline under the project's common evaluation policy.

## Reference setup

- Source: DWD RADKLIM-YW.
- Region: fixed 128 x 128 km Ruhrgebiet ROI.
- Resolution: 1 km, 5-minute cadence.
- Input history: 12 frames / 60 minutes.
- Direct forecast leads: +5, +10, +15, +20, +25, +30 minutes.
- Model: deterministic U-Net reference model.
- Baseline: persistence.
- Seeds: 17, 42, 73.
- Reference-seed selection: median best validation loss.
- Reference seed: 17.
- Test samples: 1,135.
- Test data are never used for model or seed selection.

The canonical multi-seed run selected the following checkpoints:

| Seed | Best epoch | Best validation loss |
|---:|---:|---:|
| 17 | 12 | 0.006204 |
| 42 | 8 | 0.006177 |
| 73 | 14 | 0.006264 |

## Held-out test result

Across all six forecast leads, the learned model improves substantially over
persistence:

| Metric | Learned U-Net | Persistence | Skill |
|---|---:|---:|---:|
| MAE [mm/h] | 0.02014 +/- 0.00099 | 0.03338 | 39.7% +/- 3.0% |
| RMSE [mm/h] | 0.39030 +/- 0.00328 | 0.58816 | 33.6% +/- 0.6% |

Positive continuous-error skill is retained at every evaluated lead:

| Lead | MAE skill | RMSE skill |
|---:|---:|---:|
| +5 min | 37.8% | 31.9% |
| +10 min | 40.0% | 33.9% |
| +15 min | 40.3% | 34.5% |
| +20 min | 41.5% | 34.3% |
| +25 min | 40.3% | 34.0% |
| +30 min | 37.7% | 32.8% |

The improvement is not explained only by the prevalence of dry pixels. On the
wet-target subset, aggregate MAE skill is 41.3% and aggregate RMSE skill is
33.6%.

## Event-detection behavior

The learned model also improves aggregate CSI over persistence, but performance
degrades as precipitation intensity and forecast horizon increase.

Aggregate learned-model CSI:

| Threshold | CSI |
|---:|---:|
| >= 0.1 mm/h | 0.436 |
| >= 1 mm/h | 0.408 |
| >= 5 mm/h | 0.125 |

The strongest limitation is intense precipitation at longer lead times. For the
5 mm/h threshold, learned-model CSI decreases from 0.351 at +5 minutes to 0.008
at +30 minutes. At +30 minutes, persistence reaches 0.011 at the same threshold.
This result motivates dedicated investigation of intense-rainfall behavior but
does not by itself establish the cause.

## Validation-to-test shift

The aggregate learned RMSE increases from 0.2867 on validation to 0.3903 on the
held-out test period. On the wet-target subset it increases from 0.5513 to
0.8988. This confirms that the held-out period contains materially different or
more difficult precipitation behavior and justifies retaining strict temporal
separation.

## Reproducibility and execution policy

The official reference run used Apple MPS with fixed seeds. The required MPS
backward path is not guaranteed to be bitwise deterministic, so the run was
executed through the explicit non-deterministic-MPS opt-in policy.

The three-seed mean and sample standard deviation summarize initialization
variability. They do not remove or quantify backend-level MPS
non-determinism. Claims of bitwise reproducibility are therefore intentionally
avoided.

## Interpretation

Version 0.6 validates the central first-stage hypothesis: the learned forecast
extracts useful short-term evolution from the radar history and outperforms a
transparent persistence baseline on untouched real data.

The result is deliberately bounded to this ROI, this September 2023 dataset,
this temporal split, this model configuration, and these forecast leads. It
does not establish seasonal, Germany-wide, or state-of-the-art performance.

The next scientific benchmark is therefore not a more complex neural model.
Version 0.7 introduces a classical motion-based nowcasting strategy under the
same data and evaluation contract, allowing a direct comparison of persistence,
classical nowcasting, and the U-Net reference.
